# HexaHazard

A dynamic 2D pixel-art platformer and survival game built with the Godot Engine 4. Designed to run smoothly directly in web browsers.

## 🎮 About The Game
Navigate challenging obstacles, avoid dangerous spikes, dodge falling traps, collect coins, and defeat enemies across six progressive levels using classic head-jump mechanics. 

### Key Features:
* **6 Unique Levels:** Progressive difficulty to test your platforming skills.
* **Classic Mechanics:** Jump on top of enemies' heads to defeat them.
* **Survival System:** Start with three hearts and manage your health carefully.
* **Triggered Traps:** Watch out for overhead traps that detect your movement and drop from above.
* **No AI Used:** 100% human-made art, audio, and code.

## 🕹️ Controls
* **Move Left:** `A` or `Left Arrow ←`
* **Move Right:** `D` or `Right Arrow →`
* **Jump:** `Spacebar`
